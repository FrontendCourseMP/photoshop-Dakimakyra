# PixelForge Lab - редактор изображений для лабораторных

Проект по предмету «Технологии компьютерной графики».  
Приложение работает в браузере и позволяет загружать, обрабатывать и сохранять изображения.

## Что реализовано по лабораторным

- **Лаба 1**: открытие изображения, показ на `canvas`, экспорт в `PNG`, `JPG` и в учебный формат `GB7`.
- **Лаба 2**: панель каналов и пипетка с координатами, RGB и CIELAB.
- **Лаба 3**: инструмент уровней с гистограммой, ползунками и LUT.
- **Лаба 4**: масштаб просмотра и изменение реального размера изображения с выбором интерполяции.
- **Лаба 5**: фильтрация ядром 3x3 и медианный фильтр, плюс обработка краев.

## Подробно по функционалу

### Лаба 1. Загрузка и сохранение

- Поддержка входных файлов: `.png`, `.jpg/.jpeg`, `.gb7`.
- Отрисовка изображения на основном `canvas` с сохранением пропорций.
- Фон шахматкой в зоне прозрачности.
- Экспорт в `PNG`, `JPEG`, `GB7`.
- Внизу показываются имя файла, размер и глубина цвета.

### Лаба 2. Каналы и пипетка

- В боковой панели выводятся каналы изображения.
- Состав каналов определяется форматом:
  - GB7 без маски: серый;
  - GB7 с маской: серый и альфа;
  - PNG/JPG без альфы: R, G, B;
  - PNG/JPG с альфой: R, G, B и альфа.
- Каналы можно включать и выключать кликом.
- При активной пипетке по клику выводятся:
  - `X, Y`;
  - `R, G, B`, `Alpha`;
  - HEX;
  - CIELAB (D65).

### Лаба 3. Уровни

- Открывается модальное окно «Уровни».
- Есть выбор канала: общий RGB, отдельные цветовые каналы и альфа.
- Гистограмма строится вручную на `canvas` (256 значений).
- Доступны линейный и логарифмический режимы отображения.
- Три управляющие точки: черная, средняя (гамма), белая.
- Есть точный ввод чисел для черной точки, гаммы и белой точки.
- Есть предпросмотр на холсте.
- Кнопки:
  - `Сброс` возвращает значения по умолчанию;
  - `Отмена` откатывает изменения;
  - `Применить` записывает результат через LUT.

### Лаба 4. Масштаб и изменение размера

- При загрузке изображение автоматически вписывается в рабочую область.
- Диапазон зума: `12% .. 300%`.
- В статус-баре:
  - кнопка `Fit`;
  - пресеты масштаба;
  - ручной ввод процента.
- Инструмент «Размер» меняет реальные пиксельные размеры.
- Доступны единицы:
  - проценты;
  - пиксели.
- Опция сохранения пропорций.
- Алгоритмы интерполяции:
  - ближайший сосед;
  - билинейная.

### Лаба 5. Фильтрация

- Инструмент «Фильтр» открывает отдельный диалог.
- Есть пресеты и редактируемое ядро `3x3`.
- Предустановки:
  - тождественное;
  - резкость;
  - Гаусс 3x3;
  - box blur;
  - Прюитт X;
  - Прюитт Y.
- Также есть медианный фильтр `3x3`.
- Можно выбрать, по каким каналам применять фильтр.
- Режимы краев:
  - черный;
  - белый;
  - копирование границы.
- Вычисления идут в `Web Worker`, чтобы интерфейс не зависал.

## Формат GrayBit-7 (GB7)

GB7 это несжатый формат в оттенках серого: 7 бит яркости + опциональный бит маски.

| Смещение | Размер | Описание |
|---------:|-------:|----------|
| 0 | 4 | Сигнатура `47 42 37 1D` |
| 4 | 1 | Версия (`0x01`) |
| 5 | 1 | Флаги (бит 0: есть маска) |
| 6 | 2 | Ширина (`uint16`, big-endian) |
| 8 | 2 | Высота (`uint16`, big-endian) |
| 10 | 2 | Резерв (`0x0000`) |
| 12 | `W*H` | Пиксели |

Биты `6..0` это яркость `0..127`, бит `7` это маска прозрачности.

Кодек формата находится в `src/gb7.tsx`.
