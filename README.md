# Raster Room

Учебный редактор растровой графики. Выполнил Владислав Кашкин.

Проект объединяет лабораторные работы №1–5 по компьютерной графике. Интерфейс выполнен как светлая графическая лаборатория: рабочий стол, отдельная панель инструментов и карточки параметров. Обработка изображения написана на чистом JavaScript без библиотек компьютерного зрения.

## ЗАПУСК

Для обычного запуска достаточно открыть файл `dist/index.html` двойным кликом. Загрузка файлов, встроенные примеры и все инструменты работают в таком режиме.

При работе с очень большими изображениями можно запустить локальный сервер, чтобы фильтрация использовала Web Worker:

```bash
python3 -m http.server 8091 --directory dist
```

После этого приложение  доступно по адресу `http://localhost:8091`. Без сервера фильтрация автоматически переходит в асинхронный режим и тоже остаётся доступной.

## Реализованные лабораторные

### 1. Цифровое представление изображения

- загрузка PNG, JPG, JPEG и GB7;
- собственные кодер и декодер GrayBit-7 с проверкой заголовка;
- отображение изображения на HTML5 Canvas;
- ширина, высота, формат, глубина цвета и размер файла в строке состояния;
- экспорт PNG, JPEG и GB7;
- обработка перетаскивания файла и ошибок формата.

### 2. Цветовые каналы и пипетка

- ручное переключение Grayscale, Grayscale + Alpha, RGB и RGB + Alpha, каждый режим со своей миниатюрой;
- отдельные монохромные миниатюры каналов;
- независимое включение и отключение каналов;
- показ маски при выборе только Alpha;
- пипетка с координатами изображения, RGB, HEX и CIELAB;
- правильный пересчёт координат при любом масштабе Canvas.

Режим каналов влияет на просмотр и экспорт, не удаляя цвет и прозрачность из исходного массива. Уровни и фильтры работают с исходными каналами документа независимо от режима просмотра.

Окна уровней, размера и фильтров можно открывать вместе. Перетаскивайте их за жёлтый заголовок; клавиши стрелок на сфокусированном заголовке тоже перемещают окно. Кнопка «−» сворачивает окно без потери настроек, что удобно на узком экране. Escape закрывает верхнее окно. Пипетка, масштаб, каналы, открытие и сохранение файла остаются доступны. Пипетка учитывает активный предпросмотр и режим каналов.

Холст показывает предпросмотр последнего выбранного окна уровней или фильтра; подпись над холстом указывает инструмент. Черновики разных окон не складываются. Отключение предпросмотра показывает применённые изменения. После применения инструмента остальные окна пересчитываются от нового результата с сохранением своих настроек. Загрузка другого файла закрывает старые окна и отменяет их расчёты.

### 3. Уровни

- диалоговое окно с Master, Red, Green, Blue и Alpha;
- композитная гистограмма по относительной светлоте и гистограммы каналов;
- линейная и логарифмическая шкалы;
- точки чёрного и белого, гамма от 0.1 до 9.9;
- сохранение настроек при переключении каналов;
- предпросмотр, сброс, отмена и применение;
- быстрые таблицы подстановки и обновление через `requestAnimationFrame`.

### 4. Масштабирование

- собственные алгоритмы ближайшего соседа и билинейной интерполяции;
- масштаб просмотра от 12% до 300%;
- автоматическое вписывание с отступом 50 пикселей;
- изменение размера в пикселях и процентах;
- связь пропорций, валидация, количество пикселей до и после;
- пояснение выбранного алгоритма интерполяции.

### 5. Фильтрация

- произвольное ядро 3 × 3;
- тождественное отображение, повышение резкости, Гаусс, прямоугольное размытие, два ядра Прюитта;
- медианный фильтр;
- выбор каналов и трёх стратегий края: чёрный, белый, копирование;
- предпросмотр, сброс, отмена и применение;
- обработка в Web Worker, асинхронный запасной режим и индикатор прогресса.

## Проверка

Алгоритмические тесты запускаются командой:

```bash
npm test
```

После изменения исходных JavaScript-модулей нужно обновить автономную сборку:

```bash
npm run build
```

Тот же набор можно открыть в браузере по адресу `http://localhost:8091/tests/`.
Проверки четырёх режимов, одновременных окон, порядка применения коррекций, загрузки нового файла и запасного режима фильтра: `http://localhost:8091/tests/windows.html`.

Тестовые изображения находятся в `dist/test-images` и `dist/samples`. В набор входят PNG с прозрачностью, JPEG, GB7 с маской, маленькое изображение и вертикальное изображение 1080 × 1920.

## Публикация

Для ручной публикации на Netlify нужно загрузить папку `dist`. Ссылку на сайт следует добавить сюда после публикации.
